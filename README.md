# guess-project_py


A simple Python game where the computer generates a random number between 1 and 50, and the player tries to guess it.

# Features

- Random number generation.
- Higher/lower hints.
- Input validation.
- Error handling.

# Built With

- Python
- Random Module
- While Loops
- Conditional Statements

# How to Run

Run "guess.py" using Python.

Created as a Python practice project.
